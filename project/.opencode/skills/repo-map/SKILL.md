# Regenerate the repo map

`AGENTS.md` starts with a `# Repo map` block. It exists so that nobody has to explore the
repository to find out where things live — no `glob **/*`, no recursive `find`. It is only
worth having while it is correct, so it is regenerated rather than hand-patched.

## 1. Read what is on disk

Directories only, three levels, nothing else:

```bash
find . -maxdepth 3 -type d \
  -not -path '*/node_modules*' -not -path '*/obj*' -not -path '*/bin*' \
  -not -path '*/.git*' -not -path '*/_razor*' -not -path '*/wwwroot/lib*' \
  | sort
```

Do not list files. Do not go deeper than three levels. If the result is longer than 30
directories, collapse the deepest level into a single line per parent rather than listing
every child.

## 2. Work out what each one is for

For a directory you do not recognise, look — do not guess:

```bash
ls <dir> | head -5
```

One line per directory, stating what belongs there, not what happens to be in it right now.
"Blazor pages and components" is useful; "contains 7 razor files" is not.

## 3. Write the block

Replace everything between the `# Repo map` heading and the next `---` separator in
`AGENTS.md`. Leave the rest of the file untouched — in particular the `# Always` block that
follows it.

Fixed format, always this and nothing else:

```markdown
# Repo map

Directories only, three levels. Regenerated by the `repo-map` skill; do not hand-edit.

| Path | What belongs here |
|---|---|
| `docs/blazor/` | Mirrored ASP.NET Core Blazor documentation |
| `harness/` | Conventions for requirements and ideas, plus file templates |
| `specs/E{n} …/` | Requirements: epics, features, stories |

---
```

Rules for the table:

- Sorted alphabetically by path.
- A trailing `/` on every path, so it is unmistakably a directory.
- Variable path segments as `{n}` or `…`, not one row per epic.
- One line per row, no line breaks inside a cell.
- **At most 25 rows.** The block sits above the `# Always` workflow and must not push it out
  of sight. If you need more rows, you are listing too deep — collapse a level.

## 4. Check yourself

```bash
head -40 AGENTS.md
grep -c '^|' AGENTS.md
```

Every path in the table must exist on disk, and every directory from step 1 must either
appear in the table or be deliberately collapsed into a parent row. Report which directories
you collapsed.
